## Day 2: how do we tell "ee" from "oo"?

Each vowel is built from just two pure tones at its first two formants (F1 and F2), as in Lesson 2. They sound robotic, a bit like whistled vowels. Day 35 rebuilds them the way a real voice does.

| File | Length | F1, F2 (Hz) | What to listen and look for |
|---|---|---|---|
| [day02_vowel_a_had.wav](day02_vowel_a_had.wav) | 2 s | 660, 1,720 | "a" as in *had*: the mouth is open, so F1 is high. |
| [day02_vowel_i_heed.wav](day02_vowel_i_heed.wav) | 2 s | 270, 2,290 | "ee" as in *heed*: the tongue is forward, so F2 is high. Two lines far apart. |
| [day02_vowel_u_hood.wav](day02_vowel_u_hood.wav) | 2 s | 300, 870 | "oo" as in *hood*: the tongue is back, so F2 is low. Two lines close together. |

Try recording yourself saying the same three vowels in Audacity and compare the spectrograms.

## Open them in Audacity
1. Download a file: open it on GitHub and press the **Download raw file** button.
2. In Audacity choose **File › Import › Audio…** (or drag the file into the window).
3. Press the **space bar** to play. To see the notes, click the track's name and choose **Spectrogram**.

## Load them in code

```python
import librosa

# sr=None keeps the file's own snapshot rate (important for the 8,000 Hz file)
y, sr = librosa.load("audio/day01_chirp_aliased_8000hz.wav", sr=None)
print(f"{len(y)} snapshots at {sr} a second = {len(y) / sr:.1f} seconds")
```
